# stone

**Inferno suite用のビデオファイル専用ブラウザ。日本語・英語対応。**  
**A dedicated video file browser for the Inferno suite, with Japanese and English interfaces.**

[ダウンロード / Download](https://github.com/newfrontierstudio/stone/releases/latest)

サムネイルにマウスを置くだけで大きくプレビュー。左右移動で映像を確認でき、選んだ動画をInfernoへ直接開けます。GPU対応プレビュー、ファイル名検索、名前変更・移動・ゴミ箱への移動に対応します。

Hover over a thumbnail for a large preview, then move the pointer sideways to scrub through the video. Open selected videos directly in Inferno. Includes GPU-accelerated previews, file-name search, renaming, moving and the Recycle Bin.

- Windows 10 / 11、64bit。通常再生にはWindowsで設定したプレーヤーを使います。
- 表示言語はWindowsに合わせて自動選択。「日本語 / English」で切り替えられます。
- インストーラーは約2.1MB。必要な実行環境・動画部品は初回に取得し、導入済みの共通部品は再利用します。
- Inferno連携には[Inferno](https://github.com/newfrontierstudio/inferno-studio/releases/latest)のインストールが必要です。

Windows 10 / 11, 64-bit. Playback uses your default Windows player. The interface follows your Windows language, with a Japanese / English switch. The installer is about 2.1MB; missing runtime and video components are downloaded during installation, and existing shared components are reused. [Inferno](https://github.com/newfrontierstudio/inferno-studio/releases/latest) is required for the Inferno editing shortcut.

This repository hosts downloads and documentation. The application source code is not published.
